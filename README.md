# THPSBot v4.3

## What is this!?
THPSBot is a bot for the [THPS Speedrun Discord](https://thps.run/discord). It is a bot specially designed by Anastasia that combines multiple functions: checking Twitch for live streamers, mirroring the thps.run run-submission/verification queue into Discord, running polls, managing self-assignable roles, and marking messages for awards.
